# Phaser — Fases del curso

Repositorio con las fases entregables del curso. Cada fase es un proyecto Vite independiente, con su propio `package.json` y `src/`.

## Fases

| Fase | Carpeta | Tecnologías | Cómo ejecutarla |
|------|---------|-------------|-----------------|
| 1 | [`fase1/`](fase1/) | Vue 3, Phaser 4, Vite | `cd fase1 && npm install && npm run dev` |
| 2 | [`fase2/`](fase2/) | Vue 3, Phaser 4, Vite, Tiled (mapa en `public/assets/`) | `cd fase2 && npm install && npm run dev` |

## Requisitos

- Node.js y npm instalados.

## Estructura

```
.
├── fase1/      # Fase 1: integración Vue 3 + Phaser 4
├── fase2/      # Fase 2: mapa creado con Tiled (tileset.png, mapa.json, mapa.tmx)
├── README.md
└── .gitignore
```
